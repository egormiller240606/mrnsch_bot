# ⚽️ Football Schedule Bot

Автоматизированный Telegram-бот для ежедневной рассылки расписания матчей топ-клубов: Real Madrid, Bayern, Chelsea, Inter, Barcelona и др.

## 🛠 Технологии и инструменты

* **Python 3.10** — основной язык разработки.
* **GitHub Actions** — автономный запуск скрипта по Cron-расписанию каждый день в 09:00 МСК.
* **live-football-api.com** — источник данных о расписании футбольных матчей.
* **python-telegram-bot** — библиотека для отправки сообщений в Telegram с поддержкой HTML-разметки.
* **Requests** — HTTP-запросы к внешнему API.

## 🌐 Архитектура

Проект построен по принципу **Serverless**. Код хранится в GitHub, а выполнение запускается через GitHub Actions по расписанию. API-ключи и токены хранятся в **GitHub Secrets** и передаются в среду выполнения через переменные окружения.

## 📊 Функционал

* Фильтрация матчей по ID выбранных команд.
* Автоматическая конвертация времени из UTC в московский часовой пояс (МСК).
* Группировка матчей по турнирам и лигам.
* Использование эмодзи-флагов стран для обозначения соревнований.
* Ежедневная автоматическая отправка расписания в Telegram.
